# 整个项目管理体系权限验收清单

本文档用于对整个项目管理体系的权限体系做系统性验收，覆盖菜单权限、项目对象权限、字段组权限、知识权限、回流链路权限以及关键导出与入口能力。

## 1. 验收目标

确认以下权限层协同正常：

1. 系统菜单/按钮权限
2. 项目成员角色权限
3. 项目字段组权限
4. 对象归属权限
5. 知识可见与编辑权限
6. 回流知识与来源追踪权限

## 2. 验收角色建议

至少准备以下角色样本：

1. 超级管理员
2. 项目经理
3. 交付经理
4. 负责人类角色
5. 普通成员
6. 访客
7. 仅知识管理员

## 3. 模块范围

本次验收覆盖：

1. 项目
2. 项目成员
3. 任务
4. 里程碑
5. Sprint
6. 风险
7. 变更
8. 工单
9. 知识文章
10. 项目知识空间

## 4. 菜单与按钮权限验收

检查以下页面：

1. `projectManage/index`
2. `taskManage/index`
3. `milestoneManage/index`
4. `sprintManage/index`
5. `riskManage/index`
6. `changeManage/index`
7. `ticketManage/index`
8. `content/articleManage/index`

验收点：

1. 无页面权限时不能进入
2. 无新增权限时新增按钮不显示
3. 无编辑权限时编辑按钮不显示或不可用
4. 无删除权限时删除按钮不显示
5. 无审批权限时审批相关按钮不显示

## 5. 项目对象权限验收

### 5.1 项目列表

检查点：

1. 当前用户只能看到有权访问的项目
2. 访客不能看到不属于自己可访问范围的项目
3. 管理员可见全部项目

### 5.2 项目详情

检查点：

1. 无访问权限的项目不能打开详情
2. 访客打开后动作区受限制
3. 项目经理可执行编辑/提审/结项等动作

## 6. 字段组权限验收

详见：

`项目字段组权限第一版验收清单.md`

本总清单只额外关注它与其他权限层的协同：

1. 菜单权限允许进入，但字段组权限可隐藏部分区块
2. 项目成员角色变化后，字段组权限即时生效
3. 审批中与结项状态补丁可覆盖字段组默认值

## 7. 对象归属权限验收

### 7.1 任务

检查点：

1. 负责人能看到自己负责任务
2. 非负责人但有项目访问权时，行为受项目权限与任务权限共同限制

### 7.2 风险 / 变更 / 工单

检查点：

1. 发起人、负责人、处理人、审批人进入对象详情是否符合预期
2. 列表是否只显示有权对象

## 8. 项目成员权限验收

检查点：

1. `projectMember` 为 `hidden` 时，不显示成员区块
2. `projectMember` 为 `readonly` 时，不可编辑成员列表
3. `projectMember` 为 `editable` 时，可增删改成员
4. 成员保存越权时后端能拦截

## 9. 计划与里程碑权限验收

检查点：

1. `projectPlan` 为 `hidden` 时：
   基线计划隐藏
   里程碑计划隐藏
   审批页计划区块隐藏

2. `projectPlan` 为 `readonly` 时：
   表单中仅查看，不可修改
   保存越权时后端拦截

## 10. 经营权限验收

检查点：

1. `projectBusiness` 为 `hidden` 时：
   预算、实际成本、币种、工时、业务线、行业、项目来源不显示

2. `projectBusiness` 为 `readonly` 时：
   页面只读
   保存越权拦截

3. 审批中项目：
   即使角色原本可编辑，也应收紧为只读

## 11. 结项权限验收

检查点：

1. `projectClosure` 为 `hidden` 时：
   结项标签页隐藏
   概览结项卡隐藏
   结项资料区块隐藏

2. `projectClosure` 为 `readonly` 时：
   可查看，不可修改

3. 提交结项审批时：
   无权角色不能提交

## 12. 项目知识权限验收

检查点：

1. `projectKnowledge` 为 `hidden` 时：
   知识 tab 隐藏
   概览知识卡隐藏
   新增知识入口隐藏

2. `projectKnowledge` 为 `readonly` 时：
   可查看知识，不可新增/编辑

3. `projectKnowledge` 为 `editable` 时：
   可进入知识空间并新增文章

## 13. 风险 / 变更 / 工单 -> 知识回流权限验收

检查点：

1. 有知识新增权限时可见 `转知识`
2. 已有回流文章时可见 `查看知识`
3. 有权限时可见 `重新沉淀`
4. 无权限时相关按钮不显示或提示无权
5. 重新沉淀前有确认提示

## 14. 知识来源与反向跳转权限验收

检查点：

1. 知识详情页可看到：
   `sourceType`
   `sourceProjectId`
   `sourceId`
   `templateType`

2. `查看来源` 能跳回风险/变更/工单/项目详情
3. 无来源对象访问权限时，应禁止进入或返回无权提示

## 15. 导出权限验收

覆盖页面：

1. 项目驾驶舱
2. 知识列表
3. 风险列表
4. 变更列表
5. 工单列表
6. 项目成员列表
7. 里程碑列表
8. Sprint 列表

检查点：

1. 有导出权限的角色可以导出
2. 导出文件包含当前页面可见数据
3. 导出列与当前权限态保持一致，不应导出无权字段

## 16. 审批状态协同验收

检查点：

1. 审批中项目：
   `projectBasic` 只读
   `projectBusiness` 只读
   `projectClosure` 只读
   `projectPlan` 保持原矩阵

2. 已结项/已归档项目：
   项目字段整体转只读

## 17. 负向场景验收

必须检查以下负向场景：

1. 前端手工改请求体，尝试保存隐藏字段
2. 前端手工改请求体，尝试保存只读字段
3. 尝试修改 `members`
4. 尝试修改 `milestones`
5. 尝试在无权限情况下转知识
6. 尝试访问无权项目知识来源对象

预期：

1. 后端拒绝
2. 返回明确字段组或对象权限错误

## 18. 验收记录模板

建议每个模块记录：

1. 模块名称
2. 验收角色
3. 页面路径
4. 操作步骤
5. 预期结果
6. 实际结果
7. 是否通过
8. 问题编号
