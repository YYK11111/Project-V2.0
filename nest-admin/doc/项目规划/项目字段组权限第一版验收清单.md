# 项目字段组权限第一版验收清单

本文档用于对项目字段组权限第一版做人工验收，覆盖配置、权限计算、页面显示态、保存拦截四条主链路。

## 1. 验收范围

第一版仅覆盖 `project` 对象，字段组包括：

1. `projectBasic`
2. `projectMember`
3. `projectPlan`
4. `projectBusiness`
5. `projectClosure`
6. `projectKnowledge`

页面范围包括：

1. `系统配置 -> 字段组权限`
2. `projectManage/form.vue`
3. `projectManage/detail.vue`
4. `projectManage/approval.vue`

## 2. 预置数据准备

验收前准备以下账号或角色样本：

1. 项目经理
2. 交付经理
3. 负责人类角色
4. 普通成员
5. 访客

同时准备一个包含以下数据的项目：

1. 已有项目基础信息
2. 已有项目成员
3. 已有里程碑
4. 已有预算/成本/工时
5. 已有结项资料
6. 已有知识目录与知识文章

建议同时准备三种项目状态：

1. 草稿/未审批
2. 审批中
3. 已结项或已归档

## 3. 系统配置页验收

### 3.1 标签页可见性

1. 打开 `系统配置`
2. 确认存在 `字段组权限` 标签页
3. 确认标签页内展示业务对象为 `项目`
4. 确认矩阵列包含：
   `基础组`
   `成员组`
   `计划组`
   `经营组`
   `结项组`
   `知识组`
5. 确认矩阵行包含：
   `项目经理`
   `交付经理`
   `负责人类角色`
   `普通成员`
   `访客`

### 3.2 默认值验收

检查默认矩阵是否符合预期：

1. 项目经理
   `projectBasic -> editable`
   `projectMember -> editable`
   `projectPlan -> editable`
   `projectBusiness -> editable`
   `projectClosure -> editable`
   `projectKnowledge -> editable`

2. 交付经理
   `projectBasic -> readonly`
   `projectMember -> editable`
   `projectPlan -> editable`
   `projectBusiness -> readonly`
   `projectClosure -> editable`
   `projectKnowledge -> editable`

3. 负责人类角色
   `projectBasic -> readonly`
   `projectMember -> readonly`
   `projectPlan -> readonly`
   `projectBusiness -> hidden`
   `projectClosure -> readonly`
   `projectKnowledge -> editable`

4. 普通成员
   `projectBasic -> readonly`
   `projectMember -> readonly`
   `projectPlan -> readonly`
   `projectBusiness -> hidden`
   `projectClosure -> hidden`
   `projectKnowledge -> readonly`

5. 访客
   `projectBasic -> readonly`
   `projectMember -> hidden`
   `projectPlan -> hidden`
   `projectBusiness -> hidden`
   `projectClosure -> hidden`
   `projectKnowledge -> readonly`

### 3.3 保存与回显验收

1. 修改任意一个矩阵单元格
2. 点击保存
3. 刷新页面
4. 确认配置已正确回显
5. 恢复默认值并再次保存

## 4. 权限接口验收

接口：

`GET /business/projects/field-permissions/:id`

逐角色验证：

1. 返回 `projectRole.rawRole`
2. 返回 `projectRole.matrixRole`
3. 返回 `projectRole.roleLabel`
4. 返回 `groups`
5. 返回 `fields`
6. 返回 `contextRules`

重点检查：

1. `members -> projectMember`
2. `milestones -> projectPlan`
3. `budget/actualCost/spentHours -> projectBusiness`
4. `closeSummary/closeReview -> projectClosure`

## 5. 项目表单页验收

页面：

`/projectManage/form?id=<projectId>`

### 5.1 项目经理

预期：

1. 基础组可见可编辑
2. 成员组可见可编辑
3. 计划组可见可编辑
4. 经营组可见可编辑
5. 结项组可见可编辑

检查点：

1. 可编辑基础信息
2. 可编辑项目成员
3. 可编辑里程碑
4. 可编辑预算、成本、工时
5. 可编辑结项资料

### 5.2 交付经理

预期：

1. 基础组可见只读
2. 成员组可见可编辑
3. 计划组可见可编辑
4. 经营组可见只读
5. 结项组可见可编辑

检查点：

1. 不能修改基础信息
2. 可以修改成员
3. 可以修改里程碑和基线计划
4. 不能修改预算/成本/工时
5. 可以修改结项资料

### 5.3 负责人类角色

预期：

1. 基础组可见只读
2. 成员组可见只读
3. 计划组可见只读
4. 经营组隐藏
5. 结项组可见只读

### 5.4 普通成员

预期：

1. 基础组可见只读
2. 成员组可见只读
3. 计划组可见只读
4. 经营组隐藏
5. 结项组隐藏

### 5.5 访客

预期：

1. 基础组可见只读
2. 成员组隐藏
3. 计划组隐藏
4. 经营组隐藏
5. 结项组隐藏

## 6. 项目详情页验收

页面：

`/projectManage/detail?id=<projectId>`

检查点：

1. 命中权限角色是否显示正确
2. `projectKnowledge` 为 `hidden` 时：
   概览知识卡不显示
   `知识` 标签页不显示
   `新增知识` 不显示
3. `projectClosure` 为 `hidden` 时：
   概览结项卡不显示
   `结项` 标签页不显示
4. `projectMember` 为 `hidden` 时：
   核心成员摘要不显示实际成员信息
   项目成员表不显示

## 7. 审批页验收

页面：

`/projectManage/approval?id=<projectId>`

检查点：

1. 命中权限角色显示正确
2. `projectBasic`/`projectPlan`/`projectBusiness` 隐藏后，基本信息大区块按预期消失
3. `projectMember` 隐藏后，项目成员区块不显示
4. `projectPlan` 隐藏后，里程碑计划区块不显示

## 8. 保存拦截验收

### 8.1 主表字段拦截

分别用无权角色尝试修改：

1. `projectBasic`
   例如：`name`
2. `projectBusiness`
   例如：`budget`
3. `projectClosure`
   例如：`closeReview`

预期：

1. 后端返回 403/禁止保存
2. 提示包含字段组信息
3. 提示包含字段列表

### 8.2 成员子表拦截

用无权角色修改成员列表：

1. 新增成员
2. 删除成员
3. 修改成员角色

预期：

1. 后端拒绝保存
2. 报错字段组为 `projectMember`

### 8.3 里程碑子表拦截

用无权角色修改里程碑：

1. 新增里程碑
2. 删除里程碑
3. 修改计划日期

预期：

1. 后端拒绝保存
2. 报错字段组为 `projectPlan`

## 9. 状态补丁验收

### 9.1 审批中项目

预期：

1. `projectBasic` 最多只读
2. `projectBusiness` 最多只读
3. `projectClosure` 最多只读
4. `projectPlan` 保持原矩阵值

### 9.2 已结项 / 已归档项目

预期：

1. `projectBasic` 最多只读
2. `projectPlan` 最多只读
3. `projectBusiness` 最多只读
4. `projectClosure` 最多只读
