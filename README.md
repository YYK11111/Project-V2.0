# Project-V2.0

## 目录说明

- `nest-admin/`：后端项目
- `nest-admin-frontend/`：前端项目
- `docs/`：项目文档目录

## 文档约定

- 根目录不再存放零散方案说明文档
- 历史说明文档归档到 `docs/legacy/`
- 业务方案文档归档到 `docs/business/`
- `docs/superpowers/specs/` 和 `docs/superpowers/plans/` 仅保留本地，不再推送远端

## 当前约束

- 一个分支只做一个主题
- 菜单/权限/配置类改动必须有代码记录
- 不沿脏分支继续堆功能
