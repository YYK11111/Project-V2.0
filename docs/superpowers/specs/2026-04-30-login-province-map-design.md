# 最近成功登录用户省份分布地图设计

## 背景

系统首页当前“用户地区分布”使用柱状图展示登录日志 `address` 的分组计数。这个口径会把同一账号多次登录重复计数，也容易被误解为用户资料所在地。

本次改为“中国省级地图 + 登录地点推断”，明确统计“全历史每个账号最近一次成功登录记录按省份分布”，不是用户资料所在地。

## 目标

- 新增后端地区接口，不改变现有 `getUserAreaList` 语义。
- 只统计登录成功日志。
- 先按账号去重，每个账号只取全历史最近一次成功登录记录。
- 将登录地点归一化为中国省级名称。
- 首页用中国地图替换地区柱状图。
- 无法上图的数据用小列表保留，避免“未知/本地”数据消失。
- 不依赖在线地图资源，复用前端已有 `china.json`。

## 后端设计

在 `nest-admin/src/modules/loginLogs` 中新增接口：

`GET /system/loginLogs/getUserLoginProvinceList`

返回结构：

```json
[
  { "name": "广东", "value": 3 },
  { "name": "北京", "value": 1 },
  { "name": "未知", "value": 1 }
]
```

服务逻辑：

1. 查询 `sys_login_log` 中 `is_success = Yes` 且账号非空的日志。
2. 按 `account` 分组取 `createTime` 最新的一条成功登录记录。
3. 读取该记录的 `address`。
4. 在服务层把 `address` 归一化为省级名称。
5. 按归一化后的省份聚合计数。

省份归一化规则：

- `北京市`、`北京` -> `北京`
- `广东省深圳市` -> `广东`
- `浙江杭州` -> `浙江`
- `本地`、空值、无法识别、内网地址解析失败文本 -> `未知`

归一化实现采用明确省份清单匹配，优先匹配较长名称，例如 `黑龙江`、`内蒙古`，避免被短名称误判。行政后缀如 `省`、`市`、`自治区`、`特别行政区` 只作为输入兼容，不出现在输出名称中。

## 前端设计

新增首页专用组件：

`nest-admin-frontend/src/views/index/components/ChartChinaMap.vue`

组件职责：

- 使用现有 `echarts`。
- 引入已有 `src/components/ChinaMap/china.json` 并注册为 `china` 地图。
- 接收 `{ name: string; value: number }[]` 数据。
- 将省级数据渲染到地图。
- 将 `未知` 或不属于省级地图名称的数据渲染到地图旁边或下方的小列表。
- 空数据展示项目现有空状态。
- 在桌面和窄屏下保持可读，窄屏时未知列表下移。

首页改动：

- `src/views/index/api.ts` 新增 `getAdminUserLoginProvinceList`，调用新的后端接口。
- `src/views/index/adminindex.vue` 将“用户地区分布”柱状图替换为中国地图组件。
- 标题使用“最近成功登录用户省份分布”。
- 辅助说明使用“按账号去重，取每个账号全历史最近一次成功登录地点推断”。

## 数据流

1. 用户进入系统首页。
2. 首页请求 `getAdminUserLoginProvinceList`。
3. 后端从成功登录日志中按账号取最近记录。
4. 后端归一化并聚合省份。
5. 前端地图展示省份数据。
6. 前端列表展示 `未知` 等不可上图数据。

## 错误处理

- 后端无法识别的地点统一计入 `未知`，不抛出业务异常。
- 前端请求失败沿用现有请求拦截器行为。
- 地图组件收到空数组时展示空状态。
- 地图 JSON 使用本地文件，不依赖在线资源。

## 测试与验证

后端：

- 为 `LoginLogsService` 补充单元测试。
- 覆盖同一账号多次登录只计最近一次。
- 覆盖只统计成功登录。
- 覆盖 `北京`、`北京市`、`广东省深圳市`、`浙江杭州`、`本地`、空值的归一化。
- 运行 `npm run lint` 和相关 Jest 测试。

前端：

- 类型检查 `npm run type-check`。
- 如首页结构测试需要更新，调整断言为新标题或新组件。
- 手工检查首页地图可渲染、未知列表不丢数据。

## 非目标

- 不修改用户表，不增加用户资料所在地字段。
- 不接入在线地图服务。
- 不改变现有 `getUserAreaList` 接口。
- 不实现时间范围筛选。
- 不下钻省市地图。
