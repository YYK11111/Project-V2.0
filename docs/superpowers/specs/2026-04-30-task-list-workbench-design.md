# 任务列表页工作台化设计

## 范围

本次只改造前端任务列表页：

- `nest-admin-frontend/src/views/business/taskManage/index.vue`

该页已有常用筛选、高级筛选、表格操作和协作提醒，本次只补齐与项目列表页及上一轮业务列表页一致的工作台头部和高级筛选按钮细节。

## 目标

- 增加任务列表页工作台 Hero，让首屏说明当前页面用途。
- 保留现有筛选字段，不新增后端查询参数。
- 保留现有高级筛选逻辑，并给高级筛选开关补充图标与旋转状态。
- 不改表格列、操作按钮、权限判断、进度更新和审批提交逻辑。

## 页面设计

### Hero 区

在 `RequestChartTable` 前增加轻量 Hero：

- eyebrow：任务协作
- 标题：任务工作台
- 说明：集中查看任务状态、优先级、来源、协作提醒和汇报情况，快速进入评论、汇报和审批处理。

Hero 不展示统计卡片，因为当前页面没有现成统计接口。为避免扩大后端范围，本次不新增统计请求。

### 查询区

现有分组保留：

- 常用筛选：任务名称、状态、优先级、来源类型。
- 高级筛选：评论情况、汇报情况、汇报时效。

后端 `TasksService.list` 已支持 `hasComment`、`hasReport`、`reportFreshness`，因此这些高级筛选字段继续保留。

### 高级筛选开关

在现有 `extraButtons` 中补充 `CaretBottom` 图标，并通过 `showAdvanced` 控制旋转：

- 展开时文案：收起高级筛选。
- 收起时文案：展开高级筛选。
- 图标展开后旋转 180 度。

## 样式设计

- 新增 `.task-hero`、`.task-hero__eyebrow`、`.task-hero__title`、`.task-hero__desc`。
- Hero 风格与上一轮业务列表页保持一致：浅色渐变背景、轻边框、16px 圆角、20px 内边距。
- 移动端 Hero 内边距降为 16px。
- 为 `.advanced-filter-toggle :deep(.el-icon)` 添加左边距和过渡。
- 新增 `.rotate-180` 旋转样式。

## 验证

实现后在 `nest-admin-frontend` 执行：

- `npm run type-check`

人工检查：

- 任务列表页 Hero 显示正常。
- 高级筛选按钮图标随展开状态旋转。
- 常用筛选和高级筛选字段未变化。
- 表格操作、进度更新、审批提交逻辑未变化。

## 非目标

- 不新增任务统计接口。
- 不新增查询字段。
- 不修改后端。
- 不抽取公共列表页组件。

- 无 TBD 或 TODO。
- 范围限定为任务列表页一个文件。
- 查询字段均为现有字段，且后端已支持高级筛选字段。
- 样式与上一轮业务列表页工作台风格一致。
